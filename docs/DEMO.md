# Demo video script (2:45)

Use only the live app, the synthetic PDFs in `fixtures/documents/`, and real results. Use a dedicated demo account. Never show a password, a key or a Supabase page with keys. Check the official rules page for the maximum video length before you record (the 2025 contest asked for under 3 minutes; the 2026 limit has not been confirmed).

## Before you record (10 minutes)

1. Open https://portchimera.onrender.com/api/health and wait for "ok". Open the app and sign in once so the API is awake.
2. In a fresh demo account, make sure there is no old `DEMO-001`. Have the three PDFs ready in one folder.
3. Dry run the whole script once, with a stopwatch. Close other tabs and notifications. Browser zoom 100 percent, light theme (dark theme for one quick moment is optional).
4. Do one real run of the AI reading first if you are worried about speed. The result is cached by file hash, so a repeat read of the same file is fast.
5. Have these tabs ready: the live app, the GitHub repository page, and the `.kiro` folder on GitHub.

## If something goes wrong while recording

- The API is slow on the first click: say nothing, wait, cut that part in editing.
- The AI misreads a value: that is part of the story. Correct it on screen and say "this is why a person approves".
- A route has no alternative after your closure: say so, then pick a different port from the menu. The app explains "no alternative route".

## After recording

Upload to YouTube as Public or Unlisted. Open the link in a private window to confirm it plays and has sound. Put the link in the Devpost form and in `docs/DEVPOST_DRAFT.md`.
